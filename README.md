# Власова · косметология — фронтенд

Чистые HTML + CSS + JS. Без сборщиков, фреймворков и зависимостей.
Вёрстка снята 1:1 с макета Figma (файл `Ckn3hzyn6SI9vWznzmC86X`, страница `Web`).
Структура URL и приоритеты — по документу «Структура сайта — kosmetolog-vlasova.ru».

## Структура

```
index.html                                  Главная (Figma «01»)
uslugi/uvelichenie-gub/index.html           Увеличение губ (Figma «02»)
uslugi/online-konsultaciya/index.html       Онлайн-консультация (Figma «04»)
problemy/akne/index.html                    Акне и высыпания (Figma «03»)
pamyatki/index.html                         Хаб памяток
pamyatki/posle-uvelicheniya-gub/index.html  ≈2 000 запросов/мес
pamyatki/posle-botoksa/index.html           ≈1 300
pamyatki/posle-biorevitalizacii/index.html  ≈550
pamyatki/posle-chistki-lica/index.html      ≈150
privacy/index.html · 404.html               служебные
robots.txt · sitemap.xml

css/
  tokens.css        цвета, шрифты, радиусы — токены из Figma Foundations
  base.css          сброс, fluid-масштабирование, типографика
  components.css    все компоненты из библиотеки Figma + памятки + поп-апы

js/main.js          аккордеон FAQ, поп-апы, чипы, радио, формы
assets/icons/       SVG-спрайт (он же инлайнится в каждую страницу)
partials/ · tools/  исходники генератора
```

Ссылки внутри сайта относительные и указывают на `.../index.html` — сайт
одинаково работает и открытый двойным кликом, и с сервера:

```bash
python3 -m http.server 8000
```

В `canonical` и `sitemap.xml` при этом стоят чистые адреса без `index.html`.

## Навигация

Переходы между страницами — через **футер** (колонки «Услуги» и «Разделы»),
плюс меню-шторка в шапке (иконка ☰).

## Поп-апы

Шесть штук, все по макетам Figma (`tools/popups.py`, блок «Поп-апы» в CSS):

| id | Макет | Тип | Чем открывается |
|---|---|---|---|
| `zapis` | Запись | нижняя шторка | кнопки «Записаться» |
| `sent` | Заявка отправлена | центральный модал | успешная отправка формы |
| `menu` | Меню | нижняя шторка | иконка ☰ |
| `tarif` | Выбор тарифа | нижняя шторка | «Выбрать тариф» |
| `product` | Заказать средство | нижняя шторка | пока без триггера — раздел `/uhod` из волны 3 |
| `ba` | До после | полноэкранный лайтбокс | клик по блоку «до / после» |

```html
<button data-overlay-open="zapis">Записаться</button>

<!-- с предвыбранной услугой -->
<button data-overlay-open="zapis"
        data-service="Увеличение губ — 18 000 ₽">Записаться</button>
```

Закрытие — крестик, клик по затемнению, `Esc`, любой `data-overlay-close`.
Скролл страницы блокируется, пока открыт хотя бы один поп-ап.

Высота шторок подогнана под макет — на 390×880 (артборд Figma) и на 390×844
(iPhone 14) все четыре помещаются целиком, без внутреннего скролла:

| шторка | высота |
|---|---|
| Меню | 716px (в макете 741) |
| Запись | 589px |
| Выбор тарифа | 696px |
| Заказать средство | 741px |

На экранах ниже ~700px (iPhone SE) шторка скроллится внутри себя — макет там
тоже не поместился бы. Нижний отступ учитывает `safe-area-inset-bottom`.

## Формы

Поле «Услуга» — выпадающий список из прайса, сгруппированный как в мега-меню
документа: Инъекции · Эстетика · Консультации. Список один на весь сайт —
`SERVICES` в `tools/build.py`; добавили услугу туда — она появилась во всех формах.

- Кнопка с `data-service="…"` открывает форму с уже выбранной услугой
  (страница губ → «Увеличение губ — 18 000 ₽», памятка про ботокс → «Ботокс» и т. д.).
  Значение сверяется со списком на сборке: опечатка роняет билд, а не тихо
  подставляет первую услугу.
- Ссылка «Изменить» рядом с меткой открывает список (`showPicker`).
- Валидация своя: `novalidate` + подсветка пустых полей и чекбокса согласия,
  фокус на первом незаполненном. Без этого браузер перехватывал отправку
  своим тултипом и наш обработчик не срабатывал.
- `autocomplete` на имени, телефоне и городе — автозаполнение на телефоне.

## Адаптив

Макет нарисован под ширину **390px**. Все размеры в CSS заданы в `rem`,
где `1rem = 16px` при вьюпорте 390px (`rem = designPx / 16`).

| Ширина экрана | `html { font-size }` | Поведение |
|---|---|---|
| до 375px | `15.3846px` (фикс) | обычная адаптивка: блоки переносятся, но не мельчают |
| 375 → 420px | `calc(16 * 100vw / 390)` | **всё** масштабируется пропорционально |
| от 420px | `17.2308px` (фикс) | колонка 420px по центру |

На 420px элементы на **12%** крупнее, чем на 375px. Проверено: `h1` = 30.77px
на 375px и 34.46px на 420px, горизонтального скролла нет от 320 до 768px.

## SEO

Реализовано по разделу 11 документа:

- **URL** — ЧПУ на латинице, вложенность `/uslugi/:slug`, `/problemy/:slug`, `/pamyatki/:slug`.
- **Title** — по шаблону `Услуга в Казани — цена X ₽, фото до/после | Косметолог Власова`.
  У памяток — без гео и без бренда в начале.
- **Один H1** на странице, хлебные крошки на всех вложенных.
- **Микроразметка** (`tools/seo.py`): `Physician` на всех страницах,
  `BreadcrumbList`, `Service` + `Offer` на услугах, `Article` + `HowTo` + `FAQPage`
  на памятках. Медицинские типы (`MedicalClinic`, `MedicalProcedure`) добавляются
  после получения лицензии — структура под это уже готова.
- **Open Graph**, `canonical`, `robots.txt`, `sitemap.xml`.

Домен в `tools/seo.py` — константа `SITE`, поменять в одном месте.

## Шрифты

`Onest` (заголовки, цены) и `Golos Text` (текст, кнопки) — с Google Fonts.
Для офлайна положите `.woff2` в `assets/fonts/` и замените `<link>` на `@font-face`.

## Генератор

```bash
cd tools && python3 build.py   # собрать страницы
cd tools && python3 check.py   # проверить: классы без CSS, битые ссылки
```

`build.py` — каркас, компоненты, список услуг `SERVICES` и реестр страниц; `p02.py`…`p04.py` — страницы
из Figma; `pamyatki.py` — раздел памяток и служебные страницы; `popups.py` —
поп-апы; `seo.py` — метатеги и микроразметка. Скрипт нужен только для правок:
в продакшн уезжают готовые `.html`.

## Что осталось подставить

- **Фото.** Все `.media` — плейсхолдеры цвета `surface/skin`, как в макете.
  Реальные снимки вставляются как `<img>` внутрь `.media`.
- **Тексты памяток — черновые.** У врача они уже написаны и рассылаются
  клиенткам вручную (раздел 12 документа) — надо заменить на авторские.
  Медицинские формулировки обязательно вычитать.
- **Ответы в свёрнутых пунктах FAQ** в макете не заданы (открыт только первый) —
  в разметке они пустые. `FAQPage` собирается только из пунктов с ответами.
- **Первый ответ FAQ на странице «Акне»** в макете залит текстом про филлеры —
  очевидная заглушка дизайнера, нужен свой текст.
- **Вторые карточки в каруселях отзывов** обрезаны рамкой фрейма в Figma —
  проставлены по видимому фрагменту, стоит сверить. В отзыве Камилы (главная)
  не видно хвоста фразы после «Врач объяснил, почему…».
- **Видео-отзыв** на главной — кружок-плейсхолдер. Под него нужно видео
  (или постер) и поведение по клику: сейчас это кнопка-заглушка.
- **Ссылки** соцсетей, Telegram, канала и обработчик отправки формы — заглушки `#`.
- **Картинка для соцсетей.** Положите `assets/img/og.jpg` (1200×630) и впишите
  путь в `OG_IMAGE` в `tools/seo.py` — теги `og:image` появятся сами. Пока
  константа пустая, чтобы не ссылаться на несуществующий файл.

## Отступления от макета (сознательные)

1. **В меню-шторке пункт «Уход» заменён на «Памятки»**, плюс «Памятки» добавлены
   в колонку «Разделы» в подвале. Так меню совпадает с документом (Услуги ·
   Проблемы · Памятки · Цены · Результаты · Обо мне) и остаётся ровно 6 строк —
   как в Figma. Раздел памяток — крупнейший кластер спроса (≈3 400 запросов/мес),
   без входной ссылки страницы были бы сиротами. «Уход» вернётся, когда появится
   раздел `/uhod` (волна 3); поп-ап «Заказать средство» уже готов и ждёт триггера.
2. **Шаблон памятки** нарисован не был — собран из существующих компонентов
   макета по описанию из раздела 07 документа.
3. **H1 главной** оставлен как в Figma («Врач-косметолог Анастасия Власова»),
   хотя документ просит «Врач-косметолог **в Казани**». Гео добавлено в `title`.

## Источник в Figma

Разработка ведётся по рабочей странице файла `Ckn3hzyn6SI9vWznzmC86X`. Файл
живой: при перекладке страниц **меняются id узлов**, поэтому перед правками
секцию нужно открывать в Figma заново, а не брать ранее снятые данные.

Свежий пример: секция отзывов на главной. В снятой ранее копии было две текстовые
карточки, в актуальной версии первая — **видео-отзыв** (Card / Variant2, 205×225,
кружок + плашка с именем и иконкой mute внахлёст на 8px), вторая — текстовая
300×225, зазор 12px. Остальные секции всех четырёх страниц совпали посекционно.
